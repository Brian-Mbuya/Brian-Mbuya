## 📐 Engineering Principles

1. **Resilience First:** Applications must degrade gracefully under dead-zone network conditions without losing state.
2. **Database-Enforced Security:** Security lives in database triggers and RLS policies, not just client UI.
3. **Rigorous Test Coverage:** Software is complete only when core execution paths are verified by automated tests.
